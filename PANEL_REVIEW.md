# Expert Panel Review — EGX Decision Engine

**Date:** 2026-08-31 · Seven independent reviews: Software Engineering, Financial Analysis, Technical Analysis, Quantitative Methodology, Investment Advisory, UI/UX, Data & Reliability.

---

## Panel verdict (consensus)

The app is **architecturally disciplined and presentationally honest, but it fails silently and its headline numbers are systematically flattering.** Handlers are thin, services cohesive, error contracts consistent, loading/error states real, and several hard things are done right (per-bar mark-to-market drawdown, scenario-anchored stops, fixed-fractional sizing, honest walk-forward caveats upstream). The problems cluster into five themes that every reviewer hit independently:

1. **It lies quietly.** Failed writes report `ok: true`; composite jobs record `ok=1` when every sub-step failed; there is no logging config, so a dead snapshot pipeline or a week of failed briefs would go unnoticed. The "multi-agent debate" is a deterministic if/else presented as adversarial reasoning with "confidence: High".
2. **EGX realism gaps.** Sharpe uses a 4% USD risk-free rate in a ~25% EGP environment; the portfolio ledger is gross of all fees while the backtester charges 0.8%/round trip; "intraday" alerts actually run on end-of-day Yahoo closes for `.CA` symbols; price-limit bands, T+2, and dividends are modeled nowhere; the holiday calendar exists but no scheduled job consults it (and it covers 2026 only).
3. **Signal quality defects.** The "momentum candles" scanner looks at one bar and can fire on a flat day; squeeze/momentum scans only ever see the alphabetical head of the 292-name EGX list; Bollinger band *breakouts* map to "NEUTRAL" (poisoning the header badge, snapshots, and `signal_change` alerts); the Candidates composite double-counts correlated volume/price signals and gives EGX30 names a free hit.
4. **Guardrails are prose, not mechanisms.** Nothing enforces per-trade or portfolio risk at `open_position`; the sizer defaults to a hardcoded 100,000 EGP; the EGX30 benchmark comparison is dead code; there is no journaling/review loop.
5. **Hygiene debt.** Server can't boot if the OneDrive editable package moves; zero indexes on hot query paths with unbounded table growth; cost-bearing POSTs are CSRF-able from any web page; a `javascript:` URL from Marketaux news executes on click; ~825 lines of `window.PG` copy-pasted across three pages; no mobile nav; English-only UI for an Arabic-speaking user.
